0. METHOD & SCOPE NOTE
--------------------------------------------------------------------------------
The dump is Capstone TEXT only (no raw opcode bytes). Branch opcodes/bytes below
are RECONSTRUCTED from (a) the mnemonic and (b) the encoded length, which equals
(VA of next listed instruction) - (VA of the branch): length 2 => SHORT rel8
(1-byte opcode 7x); length 6 => NEAR rel32 (2-byte opcode 0F 8x). rel operands
were recomputed as target-(VA+len) and cross-checked against the listed targets.

Opcode/flip reference used throughout:
  je/jz   74 / 0F84   <->  jne/jnz 75 / 0F85
  jb/jc   72 / 0F82   <->  jae/jnc 73 / 0F83
  jbe     76 / 0F86   <->  ja      77 / 0F87
  jl      7C / 0F8C   <->  jge     7D / 0F8D
  jle     7E / 0F8E   <->  jg      7F / 0F8F
A "flip" inverts the condition, so for any given input the OTHER successor is
taken. Flips are 1 byte (short) or 1 changed byte within the 2-byte 0F8x field
(near) — i.e. exactly the 74<->75 / 0F84<->0F85 class the task allows.

OVERALL CHARACTER
This region is almost entirely compiler-generated MSVC C++ RAII + dispatch
plumbing for one large "harness" class (member offsets 0..~0x490, embedded
std::string w/ SSO, std::function/bound-callback members, shared_ptr control
blocks, and a std::map). It contains: copy/move constructors, ~40 destructors
and deleting-dtor thunks, async "clone-and-post" task thunks, property setters
with telemetry, event-binding subscribers, and three kind-tag dispatch/format
functions. /GS stack cookies guard the two largest dispatchers.

KEY SEMANTIC FINDING: there is NO classic crackme comparator in this region —
nothing compares user-derived input against a secret constant (no memcmp/strcmp
of a key). Almost all branches are mechanical: null-guards before virtual calls,
shared_ptr refcount "==1 last-owner" tests, std::string SSO size checks, and
red-black-tree node-colour tests. The only genuine two-outcome *logic* is:
  - kind-tag dispatchers that switch on an int tag in {8, 9, 0xc}
    (0x18662b7e0, 0x18662e2c0, 0x18662ea50), and
  - bool-flag / bound-callback / status-code selectors in the property setters
    and the formatter 0x18662cf40.
The real validation almost certainly lives in callees outside this dump
(0x186632130, 0x186627e60, 0x1820a0110, consumers of the config bool cached at
[obj+0x290]) or behind the obfuscated stub at 0x18662fb70 (see end).
